# StrandLock

The fourth plugin in Kalan Hatton's Lock suite (after GrainLock, CycleLock and PulseLock): a VST3 **instrument** for Cubase on Windows that plays any sample from a piano roll of "strands", each note with its own drawable lanes for pitch, volume, vibrato, tone, formant, hollowness and how the sample is played (travel, heads, grain, refresh).

**Status: being built.** Nothing to download yet. This README will explain downloading, installing and playing once the first build is ready.

- `StrandLock-handoff/` holds the original build brief (`PROMPT.md`) and the earlier browser prototypes.
- `prototype-v4/` is the current browser prototype: the behavioural spec for the plugin, with its own tests (`node prototype-v4/tests/run-all.js`).
